# mdview · 使用说明

轻量 Markdown 本地阅读器（mdview.cn 复刻版）——双击 `.md` 文件即可像浏览网页一样阅读，无需配置。

> 技术栈：Go 1.25 + Wails v2.17 + Vue 3 + TypeScript · 安装包即单文件 `mdview.exe`（约 13MB）

---

## 一、快速上手

| 方式 | 操作 |
| --- | --- |
| 双击打开 | 将 `mdview.exe` 与 `.md` 文件关联，或把文件拖到 exe 上 |
| 拖拽 | 把 `.md` 文件拖进 mdview 窗口任意位置 |
| 右键发送到 | `Win+R` → `shell:sendto` → 把 `mdview.exe` 快捷方式放进去，之后右键 md 文件 → 发送到 → mdview |
| 命令行 | `mdview.exe "D:\notes\xxx.md"` |
| 选择目录 | 左侧「文件」页签 → 点「打开目录」，选择笔记文件夹（如 Obsidian 库）后自动列出全部 `.md` |

**单实例**：重复双击不会开新窗口，文件会转给已打开的窗口。

### 四个页签

- **目录**：自动提取文档标题生成大纲树，随滚动高亮当前小节，点击平滑跳转
- **历史**：最近打开的文件（最多 100 条），含目录与相对时间；顶部可关键字过滤，右上角可清空
- **收藏**：右键任意文件 → 收藏；条目带 ★ 可一键取消
- **文件**：当前目录的文件树（仅显示 `.md`，自动跳过 `.obsidian`/`.git`/`node_modules` 等隐藏与垃圾目录），当前打开的文件带「当前」徽标；支持打开目录 / 刷新 / 全部折叠

### 标题栏按钮

`渲染 / 源码 / 对照` · `⚙ 设置` · `⛶ 全屏` · `📌 置顶` · `─ 最小化` · `□ 最大化` · `✕ 关闭`（双击标题栏 = 最大化/还原）

**「渲染 / 源码 / 对照」三档切换**（未打开文件时置灰）：

- **渲染**：只看渲染结果
- **源码**：只看 Markdown 原始文本（带行号与轻量着色），顶部显示路径、行数/编码/大小，可一键复制全文
- **对照**：左右分栏同步显示源码与渲染结果，中间可拖拽调整比例（双击中缝等分），顶部「同步滚动」可开关

源码视图为**只读**，与官方免费版一致，不提供编辑；正文与源码各自记住滚动位置，切换不丢失。

### 右键菜单

**正文区右键**：浅色/深色主题切换 · 源码 ⇄ 渲染对照 · 复制文件路径 · 打开所在文件夹 · 导出 HTML
**文件/历史/收藏条目右键**：打开 · 收藏/取消收藏 · 复制文件路径 · 打开所在文件夹

## 三、渲染能力（对齐 mdview 官方 demo）

- GFM 全套：表格（圆角边框）、删除线、任务列表（可勾选样式）、自动链接
- 代码块：highlight.js 语法高亮（github / github-dark 主题随全局切换）、右上角语言标签、悬停显示复制按钮
- GFM Alert：`> [!NOTE] / [!TIP] / [!IMPORTANT] / [!WARNING] / [!CAUTION]` 五色提示块
- 数学公式：`$行内$` 与 `$$独立$$`（KaTeX，离线渲染）
- Mermaid 图表：```mermaid 代码块渲染成卡片图（语法错误时降级显示源码）
- SVG 图形：```svg（或内容为 `<svg>` 的 xml/html 代码块）直接渲染成图形卡片
- 图形卡片头部有「源码」按钮，可在图形与原始代码之间来回切换，另有复制按钮
- 脚注 `[^1]`、`==高亮==`、`[[双链]]`（双链按标题在当前目录内自动解析跳转）
- 本地图片：md 同目录及子目录下的 PNG/JPG/SVG/GIF/WebP 均可直接显示（内置回放路由，文件不离开本机）
- 深浅主题全局切换（含代码高亮主题联动），字号 12–28px，代码块自动换行开关——全部自动保存

## 四、常见问题（FAQ）

**Q1：双击 md 文件没有用 mdview 打开？**
打开「⚙ 设置 → 文件关联」，点「关联到 mdview」即可（写入 `HKEY_CURRENT_USER`，无需管理员权限，同时把文件图标设成 mdview 图标；点「取消关联」会还原成关联前的默认程序）。
也可以手动：右键 md 文件 → 打开方式 → 选择 mdview.exe → 勾选「始终使用此应用」，或使用上方「发送到」方案。

**Q2：目录里中文/GBK 编码的老笔记乱码吗？**
自动识别 UTF-8 / GB18030，无需手动转换。

**Q3：文件被移动/删除后历史点不开？**
历史与收藏中不存在的文件会显示为灰色，点击会提示「文件不存在」。

**Q4：想编辑怎么办？**
mdview 定位为纯阅读器（对齐官方免费版行为），不提供编辑；在文件所在文件夹右键用任意编辑器打开。

**Q5：配置与数据存放在哪里？**
`%AppData%\mdview\`（settings.json / history.json / favorites.json），删除即重置。

**Q6：双链 `[[某笔记]]` 点了没反应？**
双链按「当前打开文件所在目录」递归查找同名 md（不含扩展名），找不到会提示；请确认目标笔记在同一目录树内。

## 五、已知边界（如实说明）

- 本构建在 Linux 容器内交叉编译，**未经 Windows 实机回归**：安装/文件关联/WebView2 行为请以实机为准
- mdview 官方 Pro 功能（内置编辑器 F2/F3/F4、导出 PDF、归档管理等）不在本次复刻范围
- 导出 HTML 为单文件简化排版（内嵌基础样式），与官方「连图打包」能力有差异
- Mermaid 大图首渲有 1–2 秒解析耗时（库约 2.7MB 已内置，无网络依赖）

## 六、从源码构建

```
mdview/
├── main.go / app.go          # Wails 入口与绑定层
├── mdv/                      # 领域逻辑（设置/历史/收藏/文件树/GBK读取/图片回放/导出）
│   └── *_test.go             # Go 单元测试（go test ./...）
├── frontend/src/             # Vue3 + TS（标题栏/四页签/渲染管线/Mock 适配层）
├── frontend/public/static/   # highlight.js / KaTeX / mermaid 本地库
├── build.ps1                 # Windows 一键构建（-Clean / -Package）
└── wails.json / go.mod
```

```powershell
# 依赖：Go 1.25+、Node 18+、（可选）wails CLI v2.17
.\build.ps1            # 增量构建
.\build.ps1 -Clean     # 清理后构建
.\build.ps1 -Package   # 构建 + 打 zip
```

运行 Go 测试：`go test ./...`；前端类型检查：`cd frontend && npm run build`（vue-tsc 零错误即通过）。
