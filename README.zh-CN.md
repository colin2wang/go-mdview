# mdview

**像浏览网页一样读 Markdown —— 秒开、离线、数据不出本机。**

一款面向 Windows 的轻量原生 Markdown 阅读器。双击 `.md` 文件即可「渲染态」打开，而不是丢给编辑器——图表、公式、思维导图、实时预览，一应俱全。

## ✨ 为什么选择 mdview

- **🖱 双击即读** —— 一键关联 `.md` 后，每篇笔记都以渲染后的网页形态打开
- **🧠 思维导图视图** —— 一键把整篇文档变成 XMind 风格的思维导图，支持缩放 / 平移 / 折叠 / 导出 SVG & PNG
- **📊 图表开箱即用** —— Mermaid、SVG、KaTeX 公式、GFM Alert、表格、任务列表、脚注、`[[双链]]`，全部离线渲染
- **✍️ 实时预览编辑** —— 在对照模式中改写源码，右侧即时预览，保存时按原编码写回文件
- **📁 目录级浏览** —— 打开笔记文件夹（如 Obsidian 库），文件树、历史、收藏随手可用
- **🌗 深浅主题 × 四语言** —— 简体中文 / English / 日本語 / Deutsch，设置中即时切换
- **🔒 100% 本地** —— 单个约 13MB 的 `mdview.exe`，无运行时、无网络、无遥测；笔记永不离开你的电脑

## 📥 快速上手

| 方式 | 操作 |
| --- | --- |
| 双击打开 | 在设置中一键关联 `.md`，或把文件拖到 `mdview.exe` 上 |
| 拖拽 | 把 `.md` 文件拖进 mdview 窗口任意位置 |
| 右键发送到 | `Win+R` → `shell:sendto` → 把 `mdview.exe` 快捷方式放进去，之后右键 md 文件 → 发送到 → mdview |
| 命令行 | `mdview.exe "D:\notes\xxx.md"` |
| 选择目录 | 左侧「文件」页签 → 点「打开目录」，选择笔记文件夹（如 Obsidian 库）后自动列出全部 `.md` |

**单实例**：重复双击不会开新窗口，文件会转给已打开的窗口。

![对照模式：左侧源码、右侧渲染结果](docs/images/split-view.png)

### 四种视图模式

`源码` · `渲染` · `对照` · `思维导图`（未打开文件时置灰，思维导图仅对 Markdown 文件可用）：

- **渲染** —— 只看渲染结果（默认）
- **源码** —— 原始 Markdown 文本，顶部显示路径、行数 / 编码 / 大小，可一键复制全文；行号可在设置中开关
- **对照** —— 左源码、右渲染，中间可拖拽调整比例（双击中缝等分）；「同步滚动」按标题锚点保持两栏对齐
- **思维导图** —— 把整篇文档渲染成 XMind 风格的思维导图（见下方截图）

### 对照模式下的实时编辑

点「编辑」即可在左侧改写 Markdown，右侧即时预览；改动不落盘，点「保存」才写回原文件（GB18030 编码的笔记按原编码原子替换回写）。未保存就切换文件会提示改动将被丢弃。两栏各自记住滚动位置，切换不丢失。

### 四个侧栏页签

- **目录** —— 自动提取文档标题生成大纲树，随滚动高亮当前小节，点击平滑跳转
- **历史** —— 最近打开的文件（最多 100 条），含目录与相对时间；顶部关键字过滤，右上角一键清空
- **收藏** —— 右键任意文件即可收藏；条目带 ★ 可一键取消收藏
- **文件** —— 当前目录的文件树（Markdown 及可预览的图片 / 文本，自动跳过 `.obsidian` / `.git` / `node_modules` 等隐藏与垃圾目录），当前打开的文件带「当前」徽标；支持打开目录 / 刷新 / 全部折叠

### 标题栏按钮

四种视图模式，随后是 `⚙ 设置` · `⛶ 全屏` · `📌 置顶` · `─ 最小化` · `□ 最大化` · `✕ 关闭`（双击标题栏 = 最大化 / 还原）。

### 右键菜单

- **正文区右键** —— 浅色 / 深色主题切换 · 进入 / 退出对照模式 · 复制文件路径 · 打开所在文件夹 · 导出 HTML
- **文件 / 历史 / 收藏条目右键** —— 打开 · 收藏 / 取消收藏 · 复制文件路径 · 打开所在文件夹

## 🧩 渲染能力

- **GFM 全套** —— 表格（圆角边框）、删除线、任务列表（可勾选样式）、自动链接
- **代码块** —— highlight.js 语法高亮（github / github-dark 主题随全局切换）、右上角语言标签、悬停复制按钮
- **GFM Alert** —— `> [!NOTE] / [!TIP] / [!IMPORTANT] / [!WARNING] / [!CAUTION]` 五色提示块
- **数学公式** —— `$行内$` 与 `$$独立$$`，KaTeX 离线渲染
- **Mermaid 图表** —— ```mermaid 代码块渲染成卡片图（语法错误时降级显示源码）
- **SVG 图形** —— ```svg（或内容为 `<svg>` 的 xml/html 代码块）直接渲染成图形卡片
- **图形卡片** —— 每张卡片都有「源码」切换按钮与复制按钮
- **扩展语法** —— 脚注 `[^1]`、`==高亮==`、`[[双链]]`（按标题在当前目录内自动解析跳转）
- **思维导图** —— 标题层级即节点，`>` 引用块即备注，一级分支左右平衡；滚轮缩放、拖拽平移、点击节点折叠 / 展开；工具条提供适应 / 缩放 / 备注显隐 / 收起 / 展开 / 导出 SVG / 导出 PNG / 复制 SVG（零额外依赖，纯本地渲染）
- **本地图片** —— md 同目录及子目录下的 PNG/JPG/SVG/GIF/WebP 均可直接显示（内置本地路由，文件不离开本机）
- **独立预览** —— 直接打开图片文件用灯箱查看，打开纯文本文件按原文展示
- **主题外观** —— 深浅主题全局切换（含代码高亮联动），字号 12–28px，代码块自动换行开关，全部自动保存
- **界面语言** —— 简体中文 / English / 日本語 / Deutsch，设置中即时切换

## ❓ 常见问题（FAQ）

**Q1：双击 md 文件没有用 mdview 打开？**
打开「⚙ 设置 → 文件关联」，点「关联到 mdview」即可（写入 `HKEY_CURRENT_USER`，无需管理员权限，同时把文件图标设成 mdview 图标；点「取消关联」会还原成关联前的默认程序）。也可以手动：右键 md 文件 → 打开方式 → 选择 mdview.exe → 勾选「始终使用此应用」。

**Q2：中文 / GBK 编码的老笔记会乱码吗？**
自动识别 UTF-8 / GB18030，无需手动转换。

**Q3：文件被移动 / 删除后历史点不开？**
历史与收藏中不存在的文件会显示为灰色，点击会提示「文件不存在」。

**Q4：能编辑 Markdown 吗？**
可以 —— 切到「对照」模式点「编辑」，右侧实时预览改动；点「保存」写回原文件（按原编码回写）。它是轻量就地编辑，非完整编辑器；重度编辑仍可用你自己的编辑器打开该文件。

**Q5：配置与数据存放在哪里？**
`%AppData%\mdview\`（settings.json / history.json / favorites.json），删除即重置。

**Q6：双链 `[[某笔记]]` 点了没反应？**
双链按「当前打开文件所在目录」递归查找同名 md（不含扩展名），找不到会提示；请确认目标笔记在同一目录树内。

## ⚠️ 已知边界（如实说明）

- 编辑为轻量的就地源码编辑（对照模式 → 编辑 / 保存），非完整编辑器；官方 Pro 的其他功能（导出 PDF、归档管理等）不在本次复刻范围
- 导出 HTML 为单文件简化排版（内嵌基础样式），与官方「连图打包」能力有差异
- Mermaid 大图首渲有 1–2 秒解析耗时（库约 2.7MB 已内置，无网络依赖）

## 🔧 从源码构建

```
go-mdview/
├── main.go                   # Wails 入口（无边框窗口、单实例、embed 前端产物）
├── internal/app/             # 暴露给前端的绑定方法层（App.*）
├── internal/mdv/             # 领域逻辑（设置/历史/收藏/文件树/编码探测/图片服务/导出/文件关联）
│   └── *_test.go             # Go 单元测试
├── frontend/src/             # Vue 3 + TS SPA（标题栏/四页签/渲染管线）
├── frontend/public/static/   # highlight.js / KaTeX / mermaid 本地库
├── build.ps1                 # Windows 一键构建（-Clean / -Package）
└── wails.json / go.mod
```

```powershell
# 依赖：Go 1.25+、Node 18+、pnpm、（推荐）wails CLI v2
.\build.ps1            # 增量构建（图标缺失时生成 → 前端 → 后端 exe）
.\build.ps1 -Clean     # 清理后构建
.\build.ps1 -Package   # 构建 + 打 zip
```

构建脚本先检查图标资源（`build/appicon.png`、`build/windows/icon.ico`、`build/mdview.markdown.png`），任一缺失才执行 `generate-icon.ps1`（全部存在则跳过并输出提示），随后执行 `frontend/` 下的 `pnpm install && pnpm run build`（vue-tsc 类型检查 + vite 构建），再 `wails build`（未安装 wails CLI 时回退为 `go build -tags "desktop,production"`）。产物：`build\bin\mdview.exe`。

运行 Go 测试：`go test ./internal/mdv/`。
